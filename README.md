# 패션 상품 등록 관리 도구

Excel 상품 데이터를 일괄로 불러와 편집하고, 입력 오류를 검증한 뒤 Excel 파일로 내보내는 Streamlit 앱입니다.

## 주요 기능
- XLSX/XLS/CSV 상품 데이터 업로드
- 상품 데이터 표 편집 및 행 추가
- 필수값 누락, 중복 상품코드, 가격 오류 등 검수
- 검수 결과 엑셀 다운로드
- 오류 상품 제외 및 선택 열 내보내기
- 입력용 엑셀 양식 다운로드

## 실행 방법
1. Python 3.10 이상 설치
2. 프로젝트 폴더에서 `pip install -r requirements.txt` 실행
3. `streamlit run app.py` 실행
4. 터미널에 표시된 로컬 URL을 브라우저에서 열기

## Streamlit Community Cloud 배포
1. 이 프로젝트를 GitHub 저장소에 업로드합니다.
2. Streamlit Community Cloud에서 GitHub 계정을 연결하고 `Create app`을 선택합니다.
3. 저장소와 브랜치를 선택하고 메인 파일 경로를 `app.py`로 지정합니다.
4. 배포 후 생성된 앱 URL을 공유합니다.

## 입력 데이터
필수 열: 상품코드, 상품명, 브랜드, 카테고리, 색상, 사이즈, 판매가, 소비자가, 이미지파일명  
선택 열: 소재, 제조국, 시즌, 상품설명

현재는 업로드 파일을 앱 세션에서 처리하는 독립형 MVP이며 쇼핑몰 API 직접 연동은 포함하지 않습니다. 실제 플랫폼에 등록하기 전에는 해당 플랫폼의 최신 업로드 양식과 값 규칙에 맞춰 별도 매핑이 필요합니다.
